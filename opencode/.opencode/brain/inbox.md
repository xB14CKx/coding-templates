## Discipline

- File or delete within the same session. An inbox older than a month is not an
  inbox, it is clutter.
- If it has no evidence, it is not worth filing — delete it.
- If you cannot write the title in one line, you do not yet understand the
  note.

When the inbox empties, it stays empty.
