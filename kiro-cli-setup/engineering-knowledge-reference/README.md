# Engineering Knowledge Reference

This is optional reference material for the `.kiro` template.

It is intentionally kept outside `.kiro/` so the reusable base setup does not imply that the entire knowledge base should be loaded on every task.

Use it to populate or expand the relevant specialist documents when needed.

Preferred reasoning model:

Problem
→ Context
→ Constraints
→ Relevant concept
→ Alternatives
→ Trade-offs
→ Application
→ Verification

The concepts are technology- and programming-language-neutral.
