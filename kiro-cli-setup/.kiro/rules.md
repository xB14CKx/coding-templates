# Project Rules

This file contains project-specific rules.

## General Rules

- Inspect before modifying.
- Follow the existing project conventions unless there is a documented reason to change them.
- Do not introduce unnecessary dependencies.
- Do not introduce unnecessary architectural complexity.
- Do not silently change public behavior.
- Keep security-sensitive information out of source code and logs.
- Preserve backwards compatibility unless a breaking change is explicitly required.
- Add or update tests when behavior changes.
- Update relevant documentation when architecture or behavior changes.

## Scope Rules

Only modify files required for the requested task.
