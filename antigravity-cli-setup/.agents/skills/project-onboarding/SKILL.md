# Project Onboarding

When entering an unfamiliar repository:

1. inspect top-level structure
2. identify language/framework/runtime
3. identify package/dependency manifests
4. locate application entry points
5. locate configuration
6. locate database/migrations if present
7. locate tests
8. locate CI/CD
9. locate documentation
10. summarize architecture and conventions

Do not modify files during initial discovery unless explicitly requested.
