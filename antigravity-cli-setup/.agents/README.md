# Antigravity CLI Project Agent Setup

This `.agents` directory is the project-scoped AI configuration for Google Antigravity CLI.

Design goals:
- Keep always-relevant instructions small.
- Use focused skills for detailed engineering knowledge.
- Use specialized agents for isolated research, implementation, and validation.
- Prefer evidence and repository inspection over assumptions.
- Protect secrets, destructive operations, and production resources.
- Validate changes before declaring work complete.

The setup is intentionally stack-agnostic. Project-specific technology details belong in the repository itself or in project-specific skills.
